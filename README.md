# DermaVie Aesthetic Clinic

Modern responsive aesthetic clinic website built with React and Vite.

## Features

- Responsive design
- Booking modals
- Admin panel
- Demo appointment management
- Procedure slider
- Interactive animations
- Mobile navigation

## Technologies

- React
- React Router
- CSS3
- Vite
